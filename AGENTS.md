# AGENTS.md

**The instructions are in [CLAUDE.md](./CLAUDE.md). Read that.**

This file used to be a second copy of them, and by the time anyone noticed it had
drifted a long way from the truth: it still described the project as being in
phase P2, still explained how the macOS Keychain and Linux Secret Service
backends worked eight months after all three OS vaults were deleted, still
recorded a Windows Credential Manager backend as owed before the P5 release —
Windows is no longer supported at all — still said there were 21 discrepancies
when there are 46, and still called `docs/` read-only official reference
material, which is the opposite of what CLAUDE.md rule 7 says.

None of that was wrong when it was written. That is the point. Two files stating
the same rules is one file that will be wrong, and there is no way to tell from
the outside which of the two you are reading. It is the same failure as a
deployment guide describing a flag that was removed (CLAUDE.md rule 2.5), with
the aggravation that the reader is the thing being instructed.

So this file holds no rules. If your tool reads `AGENTS.md` by convention, follow
the pointer above.
